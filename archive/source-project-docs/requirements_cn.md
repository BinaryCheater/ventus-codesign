## 2. 工程约束

| ID | 约定 |
|---|---|
| Q01 | `specs/transformer.yaml` 是默认参数源；文档列举数值用于解释，程序不从文档解析参数 |
| Q02 | 公共输入先校验，CLI 覆盖后再校验；禁止 NaN/Infinity 参数、分数资源数量和隐式 dtype 改变 |
| Q03 | verifier 不引用 MILP row/constraint 对象；可共享冻结 IR 和 primitive 契约 |
| Q04 | backend 使用 Ruff 和 pytest；涉及模型/成本/接口的修改必须有相应回归和文档更新 |
| Q05 | 结果目录不可覆盖；新运行不能把旧 verification/summary 留作成功证据；无解/失败要显式记录 |
| Q06 | 结果 JSON v1 现有字段兼容，新增字段可选；前端独立维护，本轮不修改其代码、依赖和静态数据 |
| Q07 | 成本、数值语义或硬件抽象变化须版本化；旧结果保留原 hash，不能在重构后改名为新代码实验 |
| Q08 | 若 horizon 不是来自已验证可行上界，声明有限时间窗口，不能外推不可行性或最优性 |
| Q09 | 时间区间统一 `[start, finish)`；同 tick 释放后可复用；完整外部输入就绪后 region 启动 |
| Q10 | 新算子、融合规则或硬件类型须同步补接口、局部合法性、资源、验证与实验条件 |

## 3. 数值与硬件假设

当前可接受的 v0 简化：单个 Transformer、固定 shape、FP32；M/N/K 同一个 tile size；预定义融合/流水模板；模板内部时序固定；所有边界 tensor 在 SRAM；聚合 bank 带宽；所有参数初始在 HBM；无 spill/reload、任意 route 和 online softmax。

Matrix 的本地 scratchpad 固定并计入单元 toy 成本；SIMD/SFU 的内部寄存器和算子微实现隐含于已声明的 primitive 模型。不能据此声称已经完成逐端口/逐寄存器物理存储设计。

## 4. 结果发布用语

- “可行”：存在导出方案且独立 verifier 通过。
- “数值通过”：该次指定输入/容差下 reference 比较通过，同时 tile 索引检查通过。
- “latency 最优”：在声明的 finite menu、成本、tick/horizon 中，整数目标与有效下界闭合。
- “area tie-break 最优”：已固定最优 latency，并且第二阶段自身达到最优。
- “Pareto”：说明是完整枚举结果还是有限运行得到的非支配点；未闭合的点保留 gap。
- “实测/校准”：需要另有实现和测量证据。模型 duration、事件重放和 Python 执行耗时不能混用。

参考报告中的 57/64 µs、零 gap 和最优性属于其原模型；不属于本项目验收证据。

## 5. 测试与审核入口

当前测试目录按计算正确性 (`test_core.py`)、输入/产物契约 (`test_contracts.py`) 与版本化成本 (`test_costs.py`) 划分。成本回归覆盖单输出 tile 的并行限制、尾块/批次分工、融合 bias 读取、SIMD 吞吐、重叠敏感性及冻结 v0 成本。

`test_machine.py` 另覆盖汇编解析、手算周期、尾块/所有受限候选、固定端口仲裁、早读/重复写/缺失输出、停顿一致性、小候选 MILP 对照、成本反馈及只读快照复验。

审核顺序：输入契约 → 候选语义和端口 → 数学约束 → 独立 verifier → 数值执行 → 求解状态 → 受控比较 → 物理校准。先确认可信度，再解释性能收益。


### R16 补充：固定输入的难度选择

- 所有难度档固定workload/精度/成本，只增加硬件与软件候选，记录嵌套关系。禁止以更换输入形状替代候选增长。
- 小空间必须穷举/有效界确认最优；大空间同时给原空间有效上界、可行质量及20/180/600秒轨迹。达到90%/95%/98%/100%的定义在结果前固定。
- 领域法与随机、系统抽样、通用局部搜索共用合法性筛选与初始解；领域记忆有开/关消融。系统抽样不标成完整暴力穷举。
- 强结构求解器可以推翻“难题”判断。toy-course-v1完整空间已如此被排除。不得为获得预期排名隐藏更强基线。
- 分块流水扩张必须重新检查驻留下界、活动流量、数值覆盖和原程序子空间兼容性。任意汇编尚未作为已验收能力。


R16分块扩张回归已覆盖：旧族严格嵌套（none/local及多个窗口）、按head/row的chunk数值重组和尾块WS、真实权重重载字节数、fast/detailed驻留一致及非法程序拒绝。该能力仍为有限chunk程序族，强制重载gate与两种优先级不替代自由汇编/任意调度验收。

R16备用v3原型新增每chunk物理资源配额与任意任务优先级；10项回归验证v2嵌套、非法配额、面积不随逻辑配额下降及真实并发。尚无正式难度排名，不计入榜单选型证据。
